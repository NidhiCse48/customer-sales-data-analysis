Project Overview:
This project analyzes customer sales data using Python and Pandas to identify product performance, regional revenue, monthly sales trends, and profitability.

#Technologies Used:

Python

Pandas

Matplotlib

Jupyter Notebook

SQL (for separate database practice, only mention if relevant to this repository)

#Project Features:

Sales data creation and data handling using Pandas.

Revenue calculation using quantity and unit price.

Product-wise sales and revenue analysis.

Region-wise revenue comparison.

Monthly sales trend analysis using order dates.

Profit and profit-margin calculation using assumed product costs.

Data visualization, including a revenue and profit chart.

Summary of key business insights.

#Files in the Repository:

ay1_python.ipynb — Python practice notebook and analysis.

customer_sales_analysis.csv — Sales dataset.

revenue_profit_chart.png — Sales visualization.

students.csv and students_cleaned.csv — Student datasets used for separate data-cleaning practice.

practice.sql and join_test.sql — SQL practice files.
